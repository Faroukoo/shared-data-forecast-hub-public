# Shared Data Forecast Hub Lot 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, fail-closed local ingestion foundation that discovers, archives, parses, validates and publishes the qualified HCP IPC-2017 and IPP-2018 monthly datasets without modifying any remote system or consumer application.

**Architecture:** A one-shot TypeScript CLI composes small workspace packages for contracts, source qualification, bounded HTTP, immutable artifact storage, HCP parsing, quality gates and canonical publication. Normal tests are offline; an opt-in live run writes only to the Git-ignored `.data-hub/` directory and proves checksum idempotence against the official Moroccan CKAN resources.

**Tech Stack:** Node.js 22, npm 11 workspaces, TypeScript 5.9.3, tsx 4.23.12, Zod 4.4.3, Decimal.js 10.6.0, ExcelJS 4.4.0, Unzipper 0.12.5, ESLint 9.39.5, typescript-eslint 8.68.0, tsup 8.5.1, Node's built-in test runner.

**Spec:** `docs/superpowers/specs/2026-08-26-shared-data-forecast-hub-design.md`

## Global Constraints

- Run on Node `>=22.22.0 <23`; do not install any global dependency.
- Use npm workspaces and commit `package-lock.json`; do not add Nx, Turborepo, Docker, a daemon or a second language runtime.
- Pin every direct dependency exactly to the versions named in the Tech Stack; use `@types/node@22.20.1` and `@eslint/js@9.39.5`.
- Keep all generated artifacts under `.data-hub/`, which must remain Git-ignored.
- Limit a downloaded artifact to `4_194_304` bytes, HTTP redirects to `3`, and each HTTP attempt to `15_000` milliseconds.
- Before ExcelJS parsing, limit XLSX central-directory entries to `256` and declared uncompressed bytes to `33_554_432`.
- Normal tests must not access the network. Live access requires `DATA_HUB_ALLOW_NETWORK=1`.
- Accept only `data.gov.ma` and `www.data.gov.ma` for the first-lot connector, including redirect targets.
- Use the HCP IPC base-2017 monthly dataset ID `0ebb73ec-1f04-4854-b73e-a7868b0b18b0` and HCP IPP base-2018 monthly dataset ID `59a68619-4bd8-4086-8bea-5a0e4757b4d8`.
- Treat supplier metadata as advisory and locally computed SHA-256 as the equality proof.
- Preserve raw artifacts and published revisions; never overwrite bytes at an existing digest path.
- A failed mandatory quality gate must prevent publication.
- Never log credentials, cookies, authorization headers or URL credentials.
- Do not create a GitHub repository, remote, Supabase project, scheduled workflow, Vercel deployment or consumer integration in this plan.
- Use `apply_patch` for repository file edits. Keep every task as a focused local commit.

## Completion Boundary

Completing this plan proves a local, deterministic lot-1 ingestion foundation and a bounded live read from the two official HCP resources. It does not prove durable production operation.

The next design gate must cover dedicated durable storage, backup/recovery, scheduler ownership, source-health alerts, service authentication and tenant isolation before any continuous production feed is authorized.
