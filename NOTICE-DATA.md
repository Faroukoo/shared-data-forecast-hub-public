# Notice relative aux données

## Sources et attribution

Les snapshots de ce dépôt peuvent contenir exclusivement des données publiques qualifiées du **Haut-Commissariat au Plan du Royaume du Maroc (HCP)** provenant des deux fiches data.gov.ma suivantes :

- Indice des prix à la consommation, base 2017 : <https://data.gov.ma/data/fr/dataset/0ebb73ec-1f04-4854-b73e-a7868b0b18b0>
- Indice des prix à la production industrielle, énergétique et minière, base 2018 : <https://data.gov.ma/data/fr/dataset/59a68619-4bd8-4086-8bea-5a0e4757b4d8>

Les entrées du registre déclarent ces jeux sous licence **Open Database License 1.0 (ODbL-1.0)**. Chaque snapshot conserve les octets officiels archivés, l'URL et les métadonnées de provenance disponibles, les manifestes, les rapports qualité, les révisions publiées et leurs checksums SHA-256 afin de permettre l'audit de la transformation.

## Obligations de réutilisation

Toute personne qui utilise ou redistribue les données doit :

- conserver l'attribution au Haut-Commissariat au Plan et les liens vers les fiches sources ci-dessus ;
- vérifier et respecter les conditions ODbL ainsi que toute condition précisée par le producteur ou le portail source ;
- identifier clairement les transformations et ne pas présenter une donnée dérivée comme une nouvelle valeur officielle du HCP ;
- conserver les informations de provenance et de checksum utiles à la traçabilité.

Cette notice porte uniquement sur les données contenues dans les snapshots. Elle n'accorde aucun droit sur le code du dépôt. L'absence d'un fichier `LICENSE` pour le code signifie qu'aucune licence d'utilisation, de modification ou de redistribution du code n'est concédée par cette notice.
